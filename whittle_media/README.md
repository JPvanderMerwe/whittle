# whittle brand assets

Generated by `build_brand.py` in this folder. Geometry and colour come from one
source, so regenerating keeps web and native identical. Re-run with:

```
pip install cairosvg pillow "fonttools[woff]" --break-system-packages
python3 build_brand.py
```

`fonttools[woff]` rather than `fonttools`: the wordmark is set in a WOFF2 from
this repository, and fontTools needs a brotli decompressor to open one. Without
it the run stops with a line telling you this rather than an ImportError from
three frames down.

## The mark

A block with a corner pared off, the cut face lit in amber, and the shaving
lifting away from it.

It draws the name. You start with a block, you take material off, and what falls
away is a shaving - which is also, exactly, what the product does. The mark it
replaced was an isometric solid with a quarter section taken out of it: correct
for a program called bpcad, and saying nothing at all about one called whittle.

What was kept: the isometric hexagon silhouette, because it is proved to read at
16 px and every icon in the set is generated from it, and the lit interior,
because that is the recognition. What changed is that the cut is ONE flat plane
rather than three faces of a notch - a paring, not an excavation.

**The shaving crosses the block, and it has to.** The cut is taken at the near
corner, where all three visible faces meet, which on an isometric hexagon is the
centre - so a curl springing from it travels over a face whichever way it goes.
An earlier version claimed it sat outside the silhouette; it never did and never
could. What that version was right about is the failure it was trying to avoid:
a light ribbon on a dark face with a light edge behind it merges into one grey
smear at 48 px. The fix is not to route around the block but to give the ribbon
its own edge, so it is stroked in the case colour and always has a dark line
between it and whatever is behind it.

Amber `#FFB000` is the period-correct amber phosphor value, chosen over terminal
green so it reads as a CAD workstation rather than a generic hacker skin.

## Tokens

| Name | Hex | Use |
|---|---|---|
| `case` | `#0B0F0D` | app and icon background |
| `bezel` | `#151B18` | panels |
| `etch` | `#2A322D` | rules, borders |
| `grid` | `#182019` | graticule |
| `phosphor` | `#FFB000` | primary accent, active state |
| `screen` | `#DCE3DC` | the printable part, primary text |
| `dim` | `#7C8880` | secondary text |
| `pen-dim` | `#4A554E` | construction geometry |

The cut face is `phosphor` flat. The three outer faces are `#1F2723`, `#161D19`
and `#0F1512` - one per plane, so the solid reads as a solid without shading.

## Files

**source/** — edit these, not the PNGs.
`icon-master.svg` full detail, use at 512 px and above.
`icon-small.svg` simplified with heavier strokes, use below 512 px.
`mark.svg` transparent mark for splash and adaptive foregrounds.
`mark-monochrome.svg` single colour with alpha tiers for Android themed icons.

**ios/** `AppIcon-1024.png` is the only one Xcode needs for a modern asset
catalogue. The rest are included for anything that still wants explicit sizes.

**android/**
`adaptive-foreground-432.png` and `adaptive-background-432.png` for
`ic_launcher.xml`. The mark sits inside the 72 dp safe zone, so it survives
circular, squircle and rounded masks.
`adaptive-monochrome-432.png` for themed icons on Android 13+.
`play-store-512.png` for the store listing.
`legacy-launcher-*.png` for pre-adaptive densities.

**web/**
`favicon.ico` (48/32/16), `icon-16/32/48/180/192/512.png`,
`icon-*-rounded.png` for places that do not mask,
`maskable-512.png` with the 20% safe margin PWA maskable icons require.

**splash/**
`splash-logo-1152.png` centred logo for `flutter_native_splash`.
`splash-logo-android12-960.png` for the Android 12+ splash API, which crops to a
circle, so keep the mark inside the middle two thirds.
`splash-1290x2796.png`, `splash-1179x2556.png`, `splash-1080x1920.png` full
composed screens if you would rather ship images than compose at runtime.
Splash background colour is `#0B0F0D`.

**social/** `og-image-1200x630.png` for Open Graph and Twitter cards,
`twitter-600x315.png` for the smaller summary card.

**wordmark/** light and dark SVGs with the glyphs as outlines, so no font is
needed at render time, plus 2400 px PNGs.

## The wordmark

`whittle`, lowercase, set in **Space Grotesk at weight 700**, letterspaced
-0.01 em.

It has been three faces and the reasons for leaving each are worth keeping.

**JetBrains Mono Bold with an amber block cursor** said "developer tool" before
it said anything else, and the product is for somebody who wants a birdhouse,
not somebody who wants a CAD kernel. A blinking-cursor logotype was the single
most technical thing on the screen.

**Ubuntu 700** replaced it and is a good face in the wrong place. It is
instantly recognisable as Ubuntu to anyone who has seen a Linux desktop and
generically humanist to everyone else - so it is either somebody else's brand or
no brand at all. It was also loaded from `/usr/share/fonts`, so the wordmark
built differently depending on whose machine ran the script, and not at all on a
machine without it.

**Space Grotesk** is the face the product brief already names - 11.3, "Archivo
or Space Grotesk for UI, JetBrains Mono for dimensions" - it is already in this
repository, already served to the web client, and already OFL. Set beside
Archivo it is the one with letterforms of its own: flat cut terminals on the `t`
and the `e`, a squared `w`, a grotesque drawn with a straight edge rather than
defaulted to. That reads as a precision instrument without reading as a
terminal, which is the brief for this mark.

The file is `whittle/web/static/fonts/spacegrotesk-latin.woff2`, so the wordmark
and the interface are set in one thing rather than two.

## Licence note

Space Grotesk, Archivo and JetBrains Mono are all licensed under the SIL Open
Font License 1.1, which permits use in a logotype. The licence text is in
`whittle/web/static/fonts/OFL.txt`. The wordmark's glyphs are converted to
outlines in the SVGs, so the font is not redistributed by the logo - the web
client does ship the font files themselves, for UI text, which is what the OFL
text beside them covers.

## Before you ship

Check the icon against a real home screen on both platforms, in light and dark
system themes, and in the app switcher. The 16 px favicon and the Android themed
icon are the two that break first if the mark is ever changed.
